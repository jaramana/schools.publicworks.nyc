Method

This page tells you where each figure comes from, how this site calculates it, what it cannot show, and how to get the data.

Scope

New York City publishes much data about its schools. The data is in different places, and the places do not connect. The test results of a school are in one dataset. Its enrollment is in a workbook. Its address and its admissions are in a third file. The City releases that third file one time each year, for one admissions season.

This site puts these sources on one page for each school. For each value, it gives you the measure, the year, and the source.

This site is a reference. It is not a recommender. It has no overall score, no rank, and no weight. These things need a decision about what is important. A website must not make that decision for a family.

A school is on this site if New York City Public Schools publishes data about it. The data is a quality report, an enrollment snapshot, or both. This includes each district school, each District 75 special education school, each District 79 alternative program, each transfer school, and each Young Adult Borough Center.

This site uses the admissions directories to describe a school. It does not use them to add a school to the list. The directories also contain early childhood centers. The codes of those centers are not school numbers, and the directories cover one admissions season only.

A school is open if it is in the most recent enrollment snapshot or in a current directory. Each other school is closed or former, and it keeps its full history. No source publishes a status field. Thus these two labels are the reading of this site, and they can be wrong for a new school.

Sources

This site reads each reporting period from inside the data. It does not use the date on a source page. Some New York City open data pages show a recent update when only the description changed.

Joins

This site joins each source on the DBN. The DBN identifies a school in each city system. No join uses a school name. Each file spells a name differently, and a join on a name attaches the results of one school to a different school.

This site reads the borough and the district from the DBN. It does not use a lookup file, which can become old.

Calculation

Comparison groups and bands

A percentage alone is difficult to read. A result of 71 percent at Level 3 or Level 4 in English can be good or usual. The page cannot tell you which one without a reference point.

New York City supplies that reference point. For many measures it publishes two more figures with the value: the average of the comparison group of the school, and a score from 1 to 5. The score gives the result of the school against that group. The City calculates both figures against a set of schools that the City finds similar.

This site uses these two figures in three ways, and adds nothing:

  • It writes the comparison group average as a sentence, not as a second number. Thus you see the distance and the direction: 5 points more than an average of 89.2 percent.
  • If the City publishes a score, the value gets a colored band. The band contains the score, out of 5.
  • The band always has a written label with the color. A color alone is not readable for each person, and a color is not a reason.

This site groups the score of the City into four bands: 4 and more, 3 to 4, 2 to 3, and less than 2. That grouping is the only judgment on this site. The score stays visible. Thus you can disagree with the grouping and read the number.

If the City publishes no score, this site shows no color. This is usual. About one value in six has a score. A demographic figure never has one, because the enrollment of a school has no good or bad version.

A band is not a rating of the school. It describes one measure, in one year, against one comparison group of the City.

One year to a measure

Each figure in a measure comes from the same school year. That year is the year of the most recent all-students figure. If a student group has no figure in that year, this site shows it as not reported. It does not use an older number.

This rule is important. Without it, each group moves to its own most recent figure. A card then shows each group at 100 percent and English language learners at 85.7 percent, with a difference of eight years between them. That comparison is not difficult to misread. It is impossible to read correctly, and it looks like a fact about the school.

This site keeps the earlier figures. The panel of each measure has the full series, year by year.

Order of measures

In a section, a measure starts with its all-students figure. The breakdowns by student group come after it. This site shows those groups in this order: race and ethnicity, then gender, then student groups such as English language learners, then service settings, then prior achievement. In each of these, the order is alphabetical.

The alphabetical order is deliberate. A different order in a list of racial groups or ethnic groups is a judgment about which group to read first. This site has no basis for that judgment.

The names of the groups and the measures are the words of the Department of Education. This site copies them. If the source writes "Multi-Racial" or "Economic Need Index", this site writes the same. You will find these terms again in each other City document about the same school.

Units

Most percentages come as a proportion between 0 and 1. This site shows them as a percentage. A proficiency value is a scale of approximately 1.0 to 4.5. It is not a percentage.

If a source does not give a unit, this site calculates the unit from the range of the published values. It then tells you in the dictionary and on the measure. A calculated unit is a judgment. It is not a fact from the source.

Addresses and coordinates

The addresses come from the current admissions directories. The source publishes the coordinates of each high school with the address.

For each other school, this site matches the coordinate from the address with the geocoder of the New York City Department of City Planning. Thus that coordinate is a derived value. Each school records which of the two types it has. If an address does not match, this site gives no coordinate. It does not give an approximate one.

About 400 open schools have no published address, because they are not in an admissions directory. Their profiles show no address section.

Programs and admissions

Admissions occur at the program level, not at the school level. One school can operate an open program and a screened program at the same time.

This site shows the seats, the applicants, and the priority order for each program. They describe the Fall 2025 admissions season only. They are a record of one season. They are not a prediction.

Absences

This site never fills in a value, estimates a value, or writes a zero in place of a value. If it cannot read a figure from a source, the figure is absent.

There are three different types of absence, and this site keeps them apart.

  • Not reported means the source published no value for that school and that year.
  • Withheld means the source has the value but does not publish it, because the group has too few students. The measure exists and the value is protected. It is not a zero and not a low score.
  • Does not apply means the source does not publish that measure for that type of school. A graduation rate is not absent from an elementary school. No person expected it. This site removes these measures from a profile. It does not show them as gaps.

Why an absence is never a zero

A zero and a blank look similar, but they have opposite meanings. If a school has no Native American students, the enrollment snapshot gives 0.0 percent, and this site shows 0.0 percent. That is a measurement.

If the City withheld a test result for the same group, a value of 0 percent would tell you that no student in that group met the standard. No person has said that, and it is probably false. Thus a withheld figure says withheld.

Every group, every time

Below a measure, this site shows the same list of student groups for each school: each race and ethnicity, each gender, English language learners, students with disabilities, and each grade in the measure. If a group has no figure, this site lists the group with the reason.

An earlier version removed these groups, and that was worse. A race breakdown showed two groups and removed the others. The page could not tell you the reason. The school could have no such students, or the City could have withheld the figure, or this site could have an error. In one real example, the City had withheld four of the five absent groups. The City said so clearly, and the page discarded it.

Limits

Comparisons to avoid

Different years. Schools do not all report in the same year. A comparison row gives the period. It also tells you when the most recent values of two schools come from different years.

The years 2019-20 and 2020-21. The State canceled testing in spring 2020, and participation was very low in the next year. Attendance in those years includes remote days. A trend line through that period measures the pandemic, not the school.

Measures with new names. The City changed the definition of some measures between the 2017-18 and 2018-19 school years, and gave them new identifiers. This site publishes them as separate series with a note. One line would imply continuity.

Different school types. A school with grades 6 to 12 files two quality reports, one for its middle grades and one for its high school grades. It publishes some measures in both reports, for different students. This site shows two labeled rows, not one.

Different group sizes. A percentage over 12 students and a percentage over 900 students are not equally stable. If the source publishes the group size, this site shows it with the value.

A sorted comparison. You can sort the comparison table by each column. This puts a list in the order of one published measure, in one year. That is a correct thing to do, but it is not a rank of the schools. A different column often gives a different order.

Not included

  • No overall score, rank, or recommendation.
  • No commute time or travel time.
  • No address entry, zoning lookup, or interactive map.
  • No survey results. They are in workbooks that this version does not use.
  • No SHSAT figures and no specialized high school admissions figures. The high school directory has them in a separate set of columns. The documentation of those columns is not clear enough to publish safely.
  • No charter schools, except the schools in the reporting of the City.

Freshness

At least two datasets tell you that the City updates them each year. The most recent rows in those two datasets are from 2011 and 2013. This site does not use them.

If a source is later than its expected refresh window, this site shows a warning on each page. A silent old figure is worse than an absent figure.

Language

This site is in English only. The City publishes school information in nine languages, and it translates its MySchools service. If English is not your first language, start there to apply.

A translation of this site is more work than one release. Machine translation would produce confident errors about the education of a child. That is worse than this statement.

Downloads

The same pipeline writes the pages and these files, from the same validated tables. Thus the site and the downloads cannot disagree.

Three conventions to know before you open these files. Join on dbn, never on a school name. An empty value is never a zero: the status column tells you whether the source reported the value, withheld it for a small group, or published nothing. A percentage is a proportion between 0 and 1, unless the dictionary gives a different unit.

The historical sheet of the workbook has a headline set of measures for each year. The full observation table has more than 1.6 million rows, and Excel stops at approximately one million. The CSV archive has everything.

JSON

This site is static. Thus the files that its pages read are also an interface for you. There is no key and no rate limit, and CORS is open because GitHub Pages serves it that way. The paths are stable. A change to a path is a breaking change. 

data/search-index.json      every school: DBN, name, borough, district, type, grades, status
data/metrics.json           every measure: label, unit, category, which schools report it
data/sources.json           every source with its period, coverage and limits
data/status.json            build date, reporting periods, counts, display constants
data/schools/{DBN}.json     one school: identity, every series, every program

A school file has a series object, keyed by measure identifier. Each series has parallel arrays: y for the school years, v for the values, and then n for the group sizes, c for the comparison group average, s for the score of the City, b for its band, bd for a published bound such as "Above 95%", st for a status that is not a plain reported value, and rt for the report type where a school files two reports.

If a series has no st array, the source reported each value in that series. A null in v is never a zero.

Dictionary

Terms

The school data of New York City has its own vocabulary. It is not difficult, but each source assumes that you know it.

DBN
District, borough, and school number, such as 02M475. Each City school has one, and it never changes. Thus this site joins each source on it. The first two digits are the district, the letter is the borough, and the last three digits are the school.
Comparison group
A set of schools that the City finds similar to this school for one measure. The City selects the members and publishes the average of the group. It does not publish the list of the schools in the group. Thus neither this site nor you can see who is in a group.
Score out of 5
The rating of the City for one measure against that comparison group. A higher score is stronger. It is not a rating of the school.
Withheld
The City calculated a value and did not publish it, because the group has too few students. Publication could identify them. It is a protection. It is not a bad result and not a zero.
Economic Need Index
The estimate of the City of the proportion of the students of a school with economic hardship. The City calculates it from public assistance records, housing records, and similar records. It does not use a survey. A higher value means more need.
Report type
The quality report that a school files: elementary and middle, high school, transfer school, early childhood, District 75, or Young Adult Borough Center. The report type controls which measures a school publishes.
Screened, zoned, open
Admissions methods. The City sets them for each program, not for each school. Open means no academic requirement. Zoned gives priority to a student who lives in the zone of the school. Screened uses grades or other criteria.

Measures

This table gives each measure on the site, its unit, and the schools that publish it. The identifier is the value in the metric_id column of the downloads.

Build

The pipeline is four Python stages and one entry point. Run these commands: 

python -m venv .venv
.venv/bin/pip install pandas requests openpyxl XlsxWriter
.venv/bin/python run.py

The first run downloads about 230 MB and geocodes the school addresses. It takes about 15 minutes. A later run uses the two caches again.

The file pipeline/00_config.py holds each threshold, each source identifier, and each display rule. Change a value in that file, then build the site again.

Reuse

The data is free to use, but you must give attribution. Give credit to New York City Public Schools and to NYC Open Data for the data. Read this page before you cite a figure.

If a figure looks wrong, compare it with the source on the measure. If the error is on this site, report it.
