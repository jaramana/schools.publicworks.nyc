About

A public reference for New York City school statistics, built from the city's own published data.

Why

The figures exist. They are public, and they are thorough. The difficulty is that they are split across a quality report dataset, an enrolment workbook, three admissions directories and a set of files whose locations change each year, in formats that assume you already know what a DBN is and which report type a school files.

This site does the joining once, in the open, and shows the definition and the reporting period next to every value. It answers what a school publishes about itself. It does not answer which school is best, and it does not try to.

What it is built from

Static HTML, CSS and vanilla JavaScript, served from GitHub Pages. There is no framework, no build step for the site, no database and no backend. Python generates the data files; the browser only reads them.

The whole pipeline and every page are in the repository. The data is refreshed by a scheduled workflow that runs the same pipeline and publishes only after validation passes.

Independence

This site is not affiliated with, endorsed by, or connected to New York City Public Schools, the New York City Department of Education, or the City of New York. It is an independent compilation of their published data. Where a value here disagrees with an official source, the official source is correct and the error is worth reporting.

For applying to a school, use MySchools, the city's own admissions system. Nothing here is an application, an offer, or advice about eligibility.

Reuse

The compiled data and the code are free to reuse with attribution. The underlying data belongs to the agencies that publish it and carries their terms. If you republish a figure, carry its reporting period with it.
